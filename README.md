# Pretvori dvojiško število v desetiško.

Interaktivna spletna aplikacija za utrjevanje razumevanja dvojiškega sistema. Uporabnik pretvori prikazano binarno (dvojiško) število v desetiški zapis.

## Funkcionalnosti

- Izbor števila nalog (5, 10, 15)
- Izbor obsega števil (1–15, 1–31, 1–63, 1–127)
- Prikaz binarnega števila v obliki tabele (vsaka cifra posebej)
- Vnos desetiškega rezultata z možnostjo potrditve:
  - s klikom na gumb
  - ali s tipko Enter
- Takojšnje povratno sporočilo (pravilen/napačen odgovor)
- Odštevanje do naslednje naloge
- Povzetek vseh nalog v tabeli z označenimi pravilnimi in napačnimi odgovori
